## 🚀 How to Deploy to Vercel (FREE)

### Step 1 — Create GitHub account
Go to github.com → Sign up free

### Step 2 — Create a new repository
1. Click **"New"** (green button)
2. Name it: `my-journey-app`
3. Set to **Public**
4. Click **"Create repository"**

### Step 3 — Upload ALL these files
1. Click **"uploading an existing file"**
2. Drag ALL 7 files from this folder into GitHub
3. Click **"Commit changes"**

### Step 4 — Deploy on Vercel
1. Go to vercel.com → **Sign up free** (use GitHub login)
2. Click **"Add New Project"**
3. Select your `my-journey-app` repository
4. Click **"Deploy"** — done in ~30 seconds!
5. Your app is live at: `my-journey-app.vercel.app`

## 📱 Add to Phone Home Screen

### Android (Chrome)
1. Open your Vercel URL in Chrome
2. A banner will pop up: **"Add to Home Screen"** — tap it!
3. Or: tap the 3-dot menu → "Add to Home Screen"

### iPhone (Safari)
1. Open your Vercel URL in **Safari** (must be Safari!)
2. Tap the **Share button** (box with arrow)
3. Scroll down → tap **"Add to Home Screen"**
4. Tap **"Add"**

The app will appear on your home screen with the pink 🌸 icon!

## ✅ What works offline
- All tabs: Profile, Goals, Wellness, Chores, Nutrition, Fasting, Tracking, VA Journey
- Water tracker, exercise checkboxes, chore checklist
- Goal map progress
- Weight log & graph
- Recipes
- Fasting timer
- All data is saved to your phone automatically

## 🔄 Data is saved automatically
Your progress is saved to your phone's local storage — it persists between sessions!
Daily items (water, exercises, chores) reset each new day automatically.
Long-term items (goals, weight log, VA progress) are saved permanently.
